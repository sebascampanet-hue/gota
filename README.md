# Xop · Cicles Fisicoesportius Artà

App d'aprenentatge tipus joc per al mòdul de Valoració de la condició física (UF 3, el sistema nerviós), amb la Gota com a mascota.

- `index.html`: tota l'app (HTML, CSS i JS en un sol fitxer).
- `contingut.json`: lliçons i exercicis. Per afegir un tema nou, crea un altre JSON amb la mateixa estructura i afegeix-lo a `FONTS_CONTINGUT` dins `index.html`.
- Imatges de la mascota i dels exercicis.

El progrés de cada alumne es guarda al seu mòbil. El rànquing setmanal de la classe es guarda a Supabase (només sobrenom i punts).
